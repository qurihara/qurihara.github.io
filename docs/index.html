Profile Publications 栗原研究室

栗原一貴, 博士(情報理工学)

津田塾大学学芸学部情報科学科 教授 

クーリード株式会社 CTO

2012 Ig Nobel Prize winner

略歴・連絡先, English site

YouTube

情報技術を活用して人々をあっと驚かせる研究をしています。社会に開かれた研究活動を心がけておりますので、各種お気軽にご相談ください。

  • 講演・講義・パネル登壇・審査員等の依頼はこちらから。

    • 企業・大学における講演等を多数日常的に行っております。

  • 栗原研究室での共同研究の打診はこちらから。

    • 実績もあり、様々な形式があります。

  • テレビ・新聞・雑誌・Web記事取材の依頼はこちらから。

    • 多数日常的に行っております。

  • インタビューコンサルティング依頼はこちらから。

    • 製品開発やサービス開発におけるアドバイス業務やアイデア出しプロセスにおける長期的な参加などの実績があります。

  • 大学院進学の相談はこちらから。

    • 津田塾大学外部からの修士課程、博士課程への入学を受け入れています。指導できる分野はヒューマンコンピュータインタラクションおよびエンタテインメントコンピューティングです。個に寄り添う丁寧な教育を心がけており、指導した学生は学会や技術コンテストで受賞したり、IPA未踏ソフトウェア事業採択、およびスーパークリエータ認定されたり、海外大学院に進学したり、学振研究員に採用されたりといった実績が豊富にあります。研究室の学生の成果についてはこちらに一覧があります。
