前提

スマートフォンを横にして、ハーモニカのように長辺を口に当てる。照合笛の12本はスマートフォンの長辺に沿って並び、 1本の笛の本体（約66 mm）がスマートフォンの短辺（73.2 mm）とほぼ同じ長さになる。 手は、ハーモニカと同じく親指2本が下側、残りの8本が上側に来る。

論点

1. 指の数と操作の設計

画面が上向きなら8本の指が画面に乗るので、片側4つ、合わせて8つの操作面を置ける。和音の種類を組み合わせで選ぶ（和音笛）、 8種類の打楽器を叩く（リズム）といった、指の数を活かす設計ができる。画面が下向きだと親指の2本だけなので、片側2つに絞る。 どのアプリも、片側4つの操作を大事な順に並べ、親指の持ち方では先頭の2つだけを出すようにした。

片側4つをどう並べるかは、指先が画面の上でどう並ぶかによる。ハーモニカの持ち方では指先が短辺に沿って縦に並ぶと考え、 既定を「縦に4段」にした。実際の持ち方で確かめて、「持ち方と位置合わせ」で「横に4列」「2×2」に変えられる。未確認である。

2. 光らせる効果

A の持ち方では、透明な PETG の笛の真下が画面なので、吹いている笛そのものを光らせられる。音と光が同じ位置で起きるので、 観客には「どの穴が鳴っているか」が見え、演奏者には「次にどの穴を吹くか」が見える（練習・星あつめ）。 PETG の笛は床が 0.5 mm で、壁と空洞で光が散るので、どの程度明るく、どの程度隣の笛へ漏れるかは実物で確かめる必要がある。

3. 息の湿り

A と B では吹き込み口が画面の縁の上に来る。吐く息で画面が湿ると、静電容量式のタッチパネルが接触と誤認することがある。 そこで、どのアプリも板の範囲への接触は無視し、操作面は板の外側だけに置いた。それでも湿りが板の外へ広がる場合は、 板の吹き込み口の側に庇（ひさし）を付けるか、C の持ち方にする。未確認である。

4. マイクとスピーカーの位置

Pixel 7 のマイクとスピーカーは短辺の側（横に持つと左右の端）にある。そこは手で握る位置なので、手のひらで塞ぐと 笛の音が弱くなり、伴奏の音もこもる。「実機の診断」で、持ったまま笛の音の強さと回り込みを測れる。

5. スピーカーの音の回り込み

伴奏や打楽器の音がマイクに入ると、笛の検出を乱す。検出は笛の音域（1600〜3250 Hz）の山だけを見るので、 スマートフォンから出す音をすべて、この音域を抜く経路（1350 Hz より下と 3350 Hz より上だけを通す）に通すことにした。これを「保護」と呼ぶ。 笛と同じ高さの音を鳴らす必要があるとき（まねっこの手本、練習の手本、ルーパーの再生）は保護を通さず、手本の間はマイクの判定を止める。 ルーパーと動画の音は止められないので、気になるときはイヤホンを使う。

6. 画面の向きの固定

画面を下に向けたり水平に近づけたりすると、自動回転で画面の上下が入れ替わることがある。各アプリは「始める」を押したときに 全画面にして横向き（landscape-primary）に固定する。固定できない端末では、クイック設定で自動回転を止める。

おすすめ

最初は A（画面の上・画面が上） で試すのがよい。8本の指が使え、光る効果も確かめられ、4通りの中でいちばん多くのアプリが活きる。 息の湿りで誤動作する場合は C に切り替える。B と D は、画面を見ずに息と少しの操作だけで演奏する使い方（重ね音・傾きと揺れ）に絞る。
