iRecorika

スマートフォンに照合笛（12本の笛を並べた透明 PETG の板）を重ね、ハーモニカのように吹きながら、 指で画面に触れ、スマートフォンを傾けて演奏する楽器のアプリ集です。笛は G#6 から G7 までの半音階12本です。

パソコンで試すときは、各アプリの URL の末尾に ?sim=1 を付けると、マイクの代わりに 板の上を押すか、キーの 1〜0・-・^ で笛を吹いたことにできます（模擬入力で開く）。

準備

持ち方と位置合わせ笛の板を画面の上に置くか裏面に置くか、画面を上に向けるか下に向けるかを選び、画面の上の12本の帯を実物の板に合わせます。最初にここを開いてください。最初に 持ち方の検討4通りの持ち方を、画面に触れる指の数・光の見え方・息の湿り・マイクの位置で比べた検討です。読み物 実機の診断マイクで12本が取れるか、刷った笛の音程のずれ、スピーカーの音の回り込み、遅延、センサ、同時に触れる指の数を測ります。測定

見る

光る笛吹いている笛の真下（真裏）の帯を光らせます。透明な笛を画面に置くと笛そのものが光ります。音名と音程のずれも出します。光チューナー

奏でる

重ね音吹いた音をスマートフォンが別の音色で重ねます。指でオクターブを変え、半音上げ、ハモりを足します。息の強さが音量になります。吹いた音に合わせる 和音笛吹いた1音を根音にして、指で和音の種類（m・7・sus4 など）を選ぶと、スマートフォンが和音を鳴らします。吹いた音に合わせるコード 伴奏指でコードを選ぶか、有名なコード進行に沿って自動で進めるか、吹いた音からコードを自動で選ぶかして、ベース・和音・ドラムの伴奏を鳴らします。傾けてコードを進めることもできます。コード傾き リズム指で8種類の打楽器を叩き、振ってシェイカーを鳴らします。叩いたリズムをループにして、その上で吹けます。打楽器揺れ 傾きと揺れ吹いた音を重ねて鳴らし、左右に傾けて音を曲げ、前後に傾けて音色を変え、振ってトレモロをかけます。傾けて移調することもできます。傾き揺れ ルーパー吹いたフレーズを録って繰り返し、その上に次のフレーズを重ねます。1本の笛で和音やカノンを作れます。録音

練習する・遊ぶ

練習次に吹く笛の真下に印を出し、吹けたかを判定します。吹けるまで待つ「ガイド」と、拍に合わせて採点する「流れる譜面」があります。曲光 動画と一緒にYouTube や手元の動画を流しながら吹きます。指で再生・5秒戻る・区間の繰り返し・速さの変更ができます。動画 まねっこ・音当てスマートフォンが鳴らした音を笛で吹き返すゲームです。だんだん長くなる「まねっこ」と、1音ずつの「音当て」があります。耳ゲーム 星あつめ帯を流れてくる星を、線に来たときにその笛を吹いて取ります。穴の位置を体で覚えます。ゲーム光 記録帳吹いた音の高さと長さを記録し、再生し、文字列や URL にして持ち出します。記録 メロディ錠決めた旋律を吹くと、その旋律から作った鍵で暗号化しておいた伝言が開きます。暗号笛の考え方を手元で試せます。暗号
