# iRecorika

スマートフォン（Pixel 7）に照合笛（12本の笛を並べた透明 PETG の板）を重ね、ハーモニカのように吹きながら、
画面のタッチと加速度センサで音楽的な入力をする楽器を、HTML アプリとして作るプロジェクトである。
Recorika（音階カード笛）の応用として 2026-09-27 に始めた。

- 正本（経緯・タスク管理表・決定事項）: https://scrapbox.io/qurihara/iRecorika
- 公開先: https://www.unryu.org/ai-fue/irecorika/

マイクと加速度センサは HTTPS でないと使えない。ai-fue のリポジトリは非公開で GitHub Pages が動いていないので、
正本はここ（`docs/irecorika/`）に置き、`python3 scripts/export_irecorika.py` で個人サイト（qurihara.github.io）の
`papers/ai-fue/irecorika/` と `docs/ai-fue/irecorika/` へ写して配信する。写し先を直接直さない。
写すときに `docs/cipher/fft_peak.js` を `lib/fft_peak.js` として同梱し、ページの参照を書き換える。

## 共通部品（lib/）

- `irk-common.js` … 版の番号（VERSION）、設定の保存、笛の並びの座標、音名、全画面、傾きと揺れ
- `irk-audio.js` … 笛の検出（`../cipher/fft_peak.js` の FFT の山を追う方式）、保護つきの音源、打楽器、拍の時計
- `irk-stage.js` … 演奏画面（中央に12本の帯、左右に指の操作面、設定の画面）
- `irk-theory.js` … 調・和音・コード進行・曲
- `irk.test.js` … 部品の検査。`node docs/irecorika/lib/irk.test.js` で走る

## 設計の要点

- 持ち方は「笛の板を画面の上に置くか裏面に置くか」と「画面を上に向けるか下に向けるか」の4通り。
  手は親指2本が下、残りの8本が上なので、画面が上向きなら指8本、下向きなら親指2本が画面に触れる。
  各アプリは片側4つの操作を大事な順に並べ、親指の持ち方では先頭の2つだけを出す。
- 板の範囲への接触は無視する（息の湿りによる誤動作を避けるため）。操作面は板の外側だけに置く。
- スマートフォンから出す音は、笛の音域（1600〜3250 Hz）を抜く経路（保護）に通し、マイクへの回り込みで検出が乱れないようにする。
  笛と同じ高さで鳴らす手本は保護を通さず、その間はマイクの判定を止める。
- パソコンで試すときは URL に `?sim=1` を付ける。板の上を押すか、キーの 1〜0・-・^ で笛を吹いたことになる。

## 版の履歴

- v1（2026-09-27）… 最初の版。上の17ページと共通部品。実機（Pixel 7）ではまだ確かめていない。
  パソコンのブラウザで模擬入力を使い、各ページが誤りなく開き、検出・判定・再生が動くことだけを確かめた。

版を上げるときは `lib/irk-common.js` の VERSION と、各ページが読み込む `?v=` の値を揃えて上げる
（GitHub Pages の配信が古いファイルを出し続けないようにするため）。
