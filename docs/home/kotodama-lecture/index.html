01α. ことだまレクチャー（教育関係者向け）

使ってみる

活用例を見る

開発に参加する

ことだまレクチャーは、マウスまたは電子ペンだけで編集と発表ができる授業・プレゼンテーションツールです。

「キーボードも苦手とおっしゃるようなコンピュータに詳しくない方でも使えるように。」

それがことだまの目標です。

紙にペンでものを書くように。そこからはじめればきっと誰でもコンピュータも使いこなせるようになれるはずです！

現在公立の小中高校で実際に先生方に授業用として使ってもらっています。（写真）
