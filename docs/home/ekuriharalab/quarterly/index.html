Profile Publications 栗原研究室

四半期ごとの提供案内

e栗原研究室のトップへ戻る

e栗原研究室では、3か月ごとに試作デバイスを支援者の皆さんへお送りしています。その期にお選びいただけるデバイスと、それぞれの使い方を、案内としてまとめています。

お申し込みの方法は、CAMPFIREコミュニティと Discord で、支援者の皆さんに直接お知らせしています。このページには掲載していません。

提供の考え方

  • そのときすぐにお渡しできるものを提供します。これから設計や検証が必要なものは、完成時期をお約束できないためです。
  • 少数の3Dプリンタで順に製造してお送りするため、お時間をいただきます。
  • 1回の選択でお手元のコントローラに最適なものが選べるとは限りません。四半期ごとの機会を通じて、合うものを見つけていただければと考えています。
  • 試作品ですので壊れやすく、品質も万全ではありません。返品や交換には応じかねます。

これまでの提供

  • 2026年8月期　準備中です。
  • 2026年5月期　Type-DNA-Dual Φ30 Ver.1 を追加しました。
  • 2026年2月期　導電性固定具 Ver.3（Φ24、Φ30）を追加しました。
  • 2025年11月期　One-Nail Ver.1（Low と High、Φ24 と Φ30）を追加しました。
  • 2025年8月期　MHK式 Ver.1（Type-DNA-Flat、Type-DNA-B）と、タッチボタン Scratch Ver.1 を追加しました。
  • 初回特典（2025年5月）　タッチ入力栗原式インパクトボタン改と、垂直押しボタン式の固定具 Ver.1、Ver.2 を提供しました。

各デバイスの詳しい説明は、試作デバイス一覧にまとめています。

これらのデバイスを手にするには

ここで紹介しているデバイスは市販していません。CAMPFIREコミュニティ「e栗原研究室」にご参加いただいた方へ、四半期ごとにお送りしています。開発の議論にもご参加いただけます。
