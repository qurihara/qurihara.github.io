20. The Universal Background Filter

The Universal Background Filter for SNS Profile Picture

テロに備えてSNSのプロフィール画像を万国旗のアニメーションにするサービス

改め

世界平和を祈念してSNSのプロフィール画像を万国旗のアニメーションにするサービス

A web app that creates your SNS profile picture that contains ALL the national flags in the world. No terrorism, and pray for peace.

SNSのプロフィール写真の背景に世界中のすべての国の国旗をアニメーションさせる画像を生成する、平和のためのサービス。


2020/4/10追記： コロナウイルス災害に対し、本気で世界平和を祈るときがきました！

+ =

2015年のパリのテロのあと、Facebookが「自分のプロフィール画像の背景をフランス国旗にして哀悼の意を示そう」という画像加工サービスをはじめました。しかし、「パリだけじゃないだろ。全世界の平和を祈るべきだ」という批判が相次ぎました。私も全くその通りだと思います。そこで、文字通り全世界の国の国旗を背景にすることで平和を祈るプロフィール画像加工アプリを作りました。

私はフランスとかベルギーとか特定の国に限定せず、世界中のすべての国の平和を思っています。でもそれは、つまりどの国もたいして思っていないのと同じではないでしょうか。実際にできた自分のプロフィール画像（facebookで使ってます）を見ていると、どの国旗もほとんど見えません。平等に何かに思いを寄せるというのは、とても薄っぺらい気持ちであることがわかります。まさに薄っぺらい、自分にぴったりのプロフィール画像です。

・・・百歩譲って、テロは私たちの過剰反応を得るのが目的の一つであるので、予めすべての国への配慮を表明していれば、テロに与しないという意思は表明できるかもしれませんね。
